# Submission review

Repeat for each batch or direct message.

- [ ] Current authorization covers these hotels, channel, content and time; host approval rules are satisfied.
- [ ] Correct hotels; no prior submission or unresolved possible duplicate.
- [ ] Dates, nightly room counts, meeting functions, attendee counts and requested setup match the intake and the current visible form.
- [ ] Contact, response deadline, attachment and requested terms are correct; optional unknowns are omitted.
- [ ] Current form limits and required fields checked; no guessed field or unverified selection.
- [ ] Final rendered page or message reviewed. Stop if blocked or uncertain.
- [ ] After sending, record actual evidence, time, hotel, channel, receipt confirmation if any, deadline and next follow-up. Do not report success without evidence.
